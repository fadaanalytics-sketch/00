# AI Video Analyzer & Smart Clip Generator

تطبيق سطح مكتب (PySide6) يعمل محليًا لتحليل فيديو واحد في كل مشروع: تفريغ صوتي
بالتوقيتات عبر Faster-Whisper، تحليل المحتوى بالذكاء الاصطناعي (Gemini أو
OpenRouter) لاستخراج الموضوعات/المقاطع المهمة، ثم قص وتصدير هذه المقاطع
كفيديوهات مستقلة عبر FFmpeg — مع دعم اختياري لوضعها داخل قالب مصمم مسبقًا.

## سير العمل

فيديو (ملف / رابط YouTube / رابط Google Drive) → تفريغ صوتي (Faster-Whisper)
→ نص بالتوقيتات → تحليل AI (مقاطع سوشيال ميديا / تقسيم محاضرة) → جدول
موضوعات → اختيار المقاطع → قص وتصدير (FFmpeg، مع أو بدون قالب).

## المتطلبات

- Python 3.10+
- [FFmpeg](https://ffmpeg.org/) مثبت ومتاح في PATH (`ffmpeg -version` يجب أن يعمل)
- GPU اختياري لتسريع Faster-Whisper (يعمل على CPU افتراضيًا)

## التثبيت

```bash
python -m venv .venv
source .venv/bin/activate  # على ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

## التشغيل

```bash
python run.py
```

## الإعدادات

من قائمة "الإعدادات" داخل التطبيق:

- اختيار مزود الذكاء الاصطناعي: Google Gemini Studio أو OpenRouter.
- إدخال API Key واسم النموذج، مع زر "اختبار الاتصال".
- اختيار نموذج Whisper الافتراضي: tiny / base / small (افتراضي) / medium / large-v3.
- تحديد مجلد الإخراج الافتراضي للفيديوهات المصدَّرة.

جميع الإعدادات، المشاريع، النصوص المفرغة، والقوالب تُحفظ محليًا في قاعدة
بيانات SQLite (لا يوجد اتصال بالإنترنت إلا عند تحميل فيديو من رابط أو
استدعاء واجهة الذكاء الاصطناعي).

## القوالب

من قائمة "القوالب" يمكن إنشاء قالب جديد: رفع صورة خلفية، تحديد مكان ومقاس
الفيديو داخل القالب (بالسحب أو بإدخال X/Y/العرض/الارتفاع رقميًا)، وإضافة عدة
عناصر نصية (نص، حجم خط، لون) يتم سحبها لتحديد موضعها. تُحفظ القوالب
لاستخدامها لاحقًا في أي مشروع.

## بنية المشروع

```
app/
  config.py           إعدادات المسارات والثوابت
  db.py                طبقة SQLite (مشاريع / موضوعات / قوالب / إعدادات)
  models.py            نماذج البيانات (Project, Segment, Topic, Template)
  video_sources.py     استيراد فيديو محلي أو تحميله من YouTube / Google Drive
  transcription.py     التفريغ الصوتي عبر Faster-Whisper
  ai_providers.py       عملاء REST لـ Gemini و OpenRouter
  analysis.py           بناء الطلبات وتحليل رد الذكاء الاصطناعي إلى جدول موضوعات
  exporter.py           قص المقاطع وتركيبها داخل القوالب عبر FFmpeg
  ui/                   واجهة PySide6 (النافذة الرئيسية، الإعدادات، محرر القوالب...)
run.py                  نقطة تشغيل التطبيق
```

## مراحل التطوير (حسب المواصفات)

1. **MVP**: واجهة + استيراد فيديو + تفريغ صوتي (Whisper) + تحليل AI + جدول
   النتائج. ✅
2. **نسخة التصدير**: قص المقاطع + نظام القوالب + إخراج الفيديو عبر FFmpeg. ✅
3. **نسخة الإنتاج**: حزم EXE (مثل PyInstaller) وتحسينات الواجهة — غير مضمّنة
   في هذه النسخة، ويمكن إضافتها لاحقًا عبر `pyinstaller run.py --onefile --windowed`.

## ملاحظات

- كل مشروع مرتبط بفيديو واحد فقط، ويُحفظ في مجلد مستقل تحت مجلد بيانات
  التطبيق (مسار مختلف حسب نظام التشغيل).
- لا توجد معاينة قبل التصدير، والجودة عالية وثابتة (H.264 CRF 18 / AAC 192k).
- دعم روابط Google Drive يتطلب أن يكون الملف قابلاً للوصول العام (أو بصلاحية
  عرض عبر الرابط).
