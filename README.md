# AI Video Analyzer & Smart Clip Generator

تطبيق سطح مكتب (PySide6) يعمل محليًا لتحليل فيديو واحد في كل مشروع: تفريغ صوتي
بالتوقيتات عبر Faster-Whisper، تحليل المحتوى بالذكاء الاصطناعي (Gemini أو
OpenRouter) لاستخراج الموضوعات/المقاطع المهمة، ثم قص وتصدير هذه المقاطع
كفيديوهات مستقلة عبر FFmpeg — مع دعم اختياري لوضعها داخل قالب مصمم مسبقًا.

## سير العمل

فيديو (ملف / رابط YouTube / رابط Google Drive) → تفريغ صوتي (Faster-Whisper)
→ نص بالتوقيتات → تحليل AI (مقاطع سوشيال ميديا / تقسيم محاضرة) → جدول
موضوعات → اختيار المقاطع → قص وتصدير (FFmpeg، مع أو بدون قالب).

## المتطلبات

- Python 3.10+
- [FFmpeg](https://ffmpeg.org/) مثبت ومتاح في PATH (`ffmpeg -version` يجب أن يعمل)
- GPU اختياري لتسريع Faster-Whisper (يعمل على CPU افتراضيًا)

## التثبيت

```bash
python -m venv .venv
source .venv/bin/activate  # على ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

## التشغيل

```bash
python run.py
```

## الإعدادات

من قائمة "الإعدادات" داخل التطبيق:

- اختيار مزود الذكاء الاصطناعي: Google Gemini Studio أو OpenRouter.
- إدخال API Key واسم النموذج، مع زر "اختبار الاتصال".
- اختيار نموذج Whisper الافتراضي: tiny / base / small (افتراضي) / medium / large-v3.
- تحديد مجلد الإخراج الافتراضي للفيديوهات المصدَّرة.

جميع الإعدادات، المشاريع، النصوص المفرغة، والقوالب تُحفظ محليًا في قاعدة
بيانات SQLite (لا يوجد اتصال بالإنترنت إلا عند تحميل فيديو من رابط أو
استدعاء واجهة الذكاء الاصطناعي).

## ميزات إضافية

- **محرك التفريغ الصوتي (محلي / سحابي)**: من الإعدادات يمكن الاختيار بين:
  - **محلي (Faster-Whisper)**: الافتراضي، يعمل بدون إنترنت لكنه يحتاج معالجة
    فعلية على جهازك (بطيء على الأجهزة الضعيفة).
  - **سحابي (Gemini)**: يستخرج الصوت من الفيديو ويرسله إلى Gemini API
    (بنفس مفتاح API المستخدم في التحليل) ليقوم بتفريغه هناك، فلا يحمّل جهازك
    أي معالجة تفريغ محليًا. يحتاج اتصال إنترنت ومزود الذكاء الاصطناعي في
    الإعدادات مضبوط على Gemini مع مفتاح API صالح. ملاحظة: توقيتات المقاطع من
    Gemini قد تكون أقل دقة من Faster-Whisper، والصوت يُرفع لخوادم Google
    (غير محلي بالكامل)، وهو خاضع لحدود الاستخدام المجاني لـ Gemini API.
- **تصدير SRT**: من تبويب "الفيديو والتفريغ الصوتي" يمكن حفظ النص المفرغ
  كملف ترجمة `.srt` بجانب المشروع.
- **اختيار لغة الفيديو**: تلقائي أو تحديد لغة معيّنة قبل بدء التفريغ الصوتي.
- **جهاز المعالجة ونوع الحساب**: من الإعدادات يمكن اختيار CPU/CUDA ونوع
  الحساب (`int8`, `float16`, ...) لتسريع Faster-Whisper حسب العتاد المتوفر.
- **الإلغاء**: يمكن إلغاء عمليات التفريغ الصوتي والتصدير أثناء تنفيذها.
- **إعادة المحاولة التلقائية**: طلبات الذكاء الاصطناعي تُعاد تلقائيًا (حتى
  4 محاولات مع تأخير متصاعد) عند فشل الشبكة أو تجاوز حد الطلبات (429) أو
  خطأ في الخادم (5xx).
- **سجل الأخطاء**: يُحفظ سجل مفصّل بالأخطاء تلقائيًا في
  `<مجلد بيانات التطبيق>/logs/app.log` لتسهيل التشخيص.
- **مقاسات قوالب جاهزة**: 9:16 (ريلز/شورتس)، 1:1، 16:9، 4:5 — بجانب إمكانية
  إدخال مقاس مخصص.

## القوالب

من قائمة "القوالب" يمكن إنشاء قالب جديد: رفع صورة خلفية، تحديد مكان ومقاس
الفيديو داخل القالب (بالسحب أو بإدخال X/Y/العرض/الارتفاع رقميًا)، وإضافة عدة
عناصر نصية (نص، حجم خط، لون) يتم سحبها لتحديد موضعها. تُحفظ القوالب
لاستخدامها لاحقًا في أي مشروع.

## بنية المشروع

```
app/
  config.py           إعدادات المسارات والثوابت
  db.py                طبقة SQLite (مشاريع / موضوعات / قوالب / إعدادات)
  models.py            نماذج البيانات (Project, Segment, Topic, Template)
  video_sources.py     استيراد فيديو محلي أو تحميله من YouTube / Google Drive
  transcription.py     التفريغ الصوتي المحلي عبر Faster-Whisper
  transcription_gemini.py  التفريغ الصوتي السحابي عبر Gemini API
  ai_providers.py       عملاء REST لـ Gemini و OpenRouter
  json_utils.py          استخراج مصفوفة JSON من ردود الذكاء الاصطناعي
  analysis.py           بناء الطلبات وتحليل رد الذكاء الاصطناعي إلى جدول موضوعات
  exporter.py           قص المقاطع وتركيبها داخل القوالب عبر FFmpeg
  ui/                   واجهة PySide6 (النافذة الرئيسية، الإعدادات، محرر القوالب...)
run.py                  نقطة تشغيل التطبيق
```

## مراحل التطوير (حسب المواصفات)

1. **MVP**: واجهة + استيراد فيديو + تفريغ صوتي (Whisper) + تحليل AI + جدول
   النتائج. ✅
2. **نسخة التصدير**: قص المقاطع + نظام القوالب + إخراج الفيديو عبر FFmpeg. ✅
3. **نسخة الإنتاج**: حزم EXE عبر PyInstaller. ✅

## بناء نسخة EXE (PyInstaller)

```bash
pip install -r requirements-dev.txt
pyinstaller pyinstaller.spec
```

الناتج يكون في `dist/AIVideoAnalyzer/`. ملاحظة: FFmpeg **غير مضمّن** داخل
الحزمة ويجب أن يكون مثبتًا ومتاحًا في PATH على جهاز التشغيل (أو يوضع بجانب
الملف التنفيذي الناتج).

## استكشاف الأخطاء

- **التفريغ الصوتي "عالق" ولا يحدث شيء**: في أول استخدام، تقوم Faster-Whisper
  بتنزيل نموذج Whisper من الإنترنت (مئات الميغابايتات)، وهذا قد يستغرق عدة
  دقائق حسب سرعة الاتصال — راقب شريط الحالة أسفل النافذة، سيظهر عليه
  "جارٍ تحميل نموذج Whisper...". إذا لم يوجد اتصال بالإنترنت أو كان محجوبًا
  (بروكسي/جدار حماية)، سيفشل التطبيق برسالة خطأ واضحة بعد 5 دقائق كحد أقصى
  بدلاً من التجمّد إلى الأبد. بعد نجاح التنزيل مرة واحدة، يعمل التفريغ بدون
  إنترنت في المرات التالية (النموذج يُحفظ محليًا في مجلد تخزين Hugging Face
  المؤقت، عادة `~/.cache/huggingface`).
- تحقق دائمًا من ملف السجل `<مجلد بيانات التطبيق>/logs/app.log` عند حدوث أي
  مشكلة غير واضحة — يحتوي على تفاصيل الخطأ الكاملة.
